# 六阶段完整工作流

> 这是把一个公众号 291 篇文章从 0 到 Obsidian 知识库的完整操作手册。每个阶段都写明：目标、工具、耗时、失败模式与对策。

---

## 阶段 0：准备（10 分钟）

**目标**：建立一个可回滚的工作区，确认 Computer Use 权限。

```bash
mkdir -p ~/wechat-archive/{links,md,shots,backup}
```

- [ ] WorkBuddy/DSH 有 **辅助功能 + 屏幕录制** 权限
- [ ] 微信 Mac 客户端已登录，公众号文章列表窗口在**内建屏、单窗口**
- [ ] 关闭其他会抢焦点的 App（否则所有点击都会被系统丢弃）

> ⚠️ 这是最容易翻车的一步：**微信失去前台 = 所有点击静默失效**，不报错、不提示。

---

## 阶段 1：链接采集（约 1 小时 / 300 篇）

**目标**：拿到全部文章的 `mp.weixin.qq.com/s/xxx` 链接，按列表顺序。

**流程**（每篇 4 步）：

1. 在文章列表点标题 → 新标签打开正文
2. 点标签栏「当前激活标签右端」的 `···` 圆钮
3. 点菜单里的「复制链接」→ 剪贴板变化即成功
4. 回到最左侧列表标签

**关键实现**：

- **后台监听剪贴板**自动写 CSV 并去重（`scripts/clipboard_watch.py`）
- 用**原生 socket** 截图做标签定位（`scripts/cua_socket_client.mjs`），避免上下文爆炸
- 标签栏检测：OCR 顶部条 → 找「当前激活标签右端」的 `···`（模板：环形三点）

**失败模式**：

| 现象 | 原因 | 对策 |
|---|---|---|
| 点卡片无反应 | 微信非前台 | 每次点击前 `activate` + 等 1.3s |
| 点 `···` 弹出的是列表页菜单 | 当前激活标签不是文章标签 | 先 OCR 确认标签标题，再点该标签右端 |
| 标签越积越多、压缩成图标 | 未关闭旧标签 | 每篇复制后点标签左侧「✕」关闭 |
| 滚动失效 | **有残留菜单在吞事件** | 每次动作前按 `Esc` |

## 阶段 2：正文下载（10 分钟 / 290 篇）

**目标**：拿到每篇的 Markdown 全文。

**两条路**：

### A. MCP 接口（快，推荐）

```js
// JSON-RPC over HTTP，先 initialize 拿 session id，再 tools/call
POST https://<download-mcp>/api/mcp
{"jsonrpc":"2.0","id":3,"method":"tools/call",
 "params":{"name":"wechat","arguments":{"url":"https://mp.weixin.qq.com/s/xxx","config":{"MD":true}}}}
// 返回 {"urls":["https://.../标题.md"]} → 直接 HTTP 拉取
```

并发 2、失败（"服务器繁忙"）退避重试，**单线程 + 2.5s 间隔**最稳（首批 43 篇限流，重试后 0 失败）。

### B. 网页批量粘贴（无 MCP 时）

打开下载站 → 文本框粘 10 条链接（换行分隔）→ 点「批量下载」→ 文件落到浏览器默认下载目录。

> 坑：该站文本框是受控组件，**用站点自己的「快速粘贴」按钮**比 Cmd+V 更可靠；批量按钮位置随文本框高度变化，必须每批重新定位。

## 阶段 3：正文清洗（15 分钟 / 291 篇）

**目标**：把下载站导出的 md 变成干净的、可入库的文稿。

**统一模板**（实测 291 篇格式完全一致）：

```
#  <标题>
<空>
原创  戴汨  戴汨  ThinkingSlow缓慢思考
<空>
_2026年11月09日 15:07_ __ _ _ _ _ _ 中国香港  _
<正文>
####  
预览时标签不可点
不喜欢
微信扫一扫  关注该公众号
...
![作者头像](http://mmbiz.qpic.cn/...)
微信扫一扫可打开此内容，使用完整服务
：  ，  ，  ...  视频  小程序  赞  ，轻点两下取消赞 ...
```

**清洗规则**：

1. 提取标题/作者/时间/地点 → 写入 front-matter
2. 删除顶部「在小说阅读器读本章 / 去阅读」
3. 从「预览时标签不可点」起**整段截断**
4. 删除 `![作者头像]` 与头像 URL 特征图
5. 保留正文图片
6. 规范空行
7. **独立引用段落**（整段被 " " 「」 包裹）转成 `> ` 引用块

脚本：`scripts/clean_markdown.py`

## 阶段 4：语义分类（20 分钟 / 291 篇）

**目标**：给每篇打 ≤3 个 tag，生成 Obsidian MOC 索引。

**7 个类别**（按这个号的语料设计，可换）：

| 类别 | 判据 |
|---|---|
| 股东信解读 | 标题含「股东信」 |
| 公司分析 | 标题含公司名 / 财报 / 资产表 / 估值 |
| 投资人与机构 | 巴菲特/芒格/格雷厄姆/VC/基金 |
| 书与博客 | 《》/ 演讲 / 访谈 / 摘录 / 笔记 |
| 投资理念 | 价值/估值/能力圈/安全边际/复利 |
| 商业与创业 | 创业/融资/增长/产品/团队 |
| 生活与思考 | 其余（认知、人生、习惯） |

**关键**：先做**级联判定**（命中即停），再人工抽查 20 条修正。纯关键词会误判约 15%，必须抽查。

## 阶段 5：互动数据（约 1 小时采集 + 10 分钟解析）

**目标**：每篇拿到 阅读 / 赞 / 转发 / 在看 / 评论 / 听全文。

### 5.1 采集：逐篇打开截图

每篇约 10 秒：切前台 1.3s → 点卡片 → 等加载 3s → 截图 → 关标签。

**必须存三种图**（后续离线反复调解析器，不用再碰微信）：

```
{publish}_full.png   整页（保留标题/正文上下文）
{publish}_bar.png    底部操作栏（赞/转发/在看/评论）
{publish}_hdr.png    顶部行（作者/时间/地点/听全文）
```

命名用 **发布时间**（`2026-04-16_11-05`），与 md 的 `publish` 字段一一对应，天然对齐。

### 5.2 解析：传统 CV（不用 GPU）

```
二值化(阈值140)
  → 连通域（8 邻接，行游程 + 并查集）
  → 图标定位：4 个图标用模板匹配（全数据集像素级一致，距离 0.0）
  → 数字分组：图标右侧、与上一字形间距 ≤26px 的窄高连通域
  → 数字识别：归一化 20×20 → 与 1000+ 已标注字形做最近邻（0–9）
  → 若右侧是宽字形（汉字）→ 该指标 = 0（微信显示「写留言」）
```

**为什么不用 OCR**：单字符细体数字 OCR 失败率 ~45%；图标粘连导致 `71→671`；`6/9` 经常互反。模板分类的类间余量 3.5×，稳定得多。

### 5.3 回填

按 `publish` 对齐 → 写入 front-matter 六个字段 → 重建核对表 xlsx。

## 阶段 6：Obsidian 化

**front-matter 模板**：

```yaml
---
title: "40岁前，不要说懂投资"
author: "戴汨"
source: "ThinkingSlow缓慢思考"
publish: "2026-11-09 15:07"
location: "中国香港"
url: "https://mp.weixin.qq.com/s/6WEVqoKTJ910YIqxFLJnpw"
listened: 73
reads: 2058
likes: 77
shares: 210
wows: 25
comments: 9
updated: 2026-11-11
tags:
  - 投资理念
---
```

**索引 `_目录.md`**：

- 分类索引（7 类，每类按时间倒序，`[[文件名]]` 双链 + 显示另两个 tag）
- 全量时间索引（按年分组）

**经验**：`[[双链]]` 必须用**文件名**（站点文件名无标点），但 `title` 字段保留完整标点 → Obsidian 搜索两种都能命中。

## 时间预算（291 篇实测）

| 阶段 | 耗时 | 备注 |
|---|---|---|
| 链接采集 | ~2.5h | 含踩坑返工 |
| 正文下载 | 15min | MCP 方案 |
| 清洗 + 分类 | 35min | 纯本地 |
| 互动数据采集 | ~60min | 含失败重试 |
| 互动数据解析 | 15min | 离线 |
| **合计** | **~4h** | 其中 ~1.5h 是踩坑调试 |
