# 40岁前，不要说懂投资

缓慢思考！ 机场写字似乎是打发时间的好方法。

芒格说过：“我不认为任何人40岁前真懂价值投资。”（I don't think anyone under forty really understands value investing.）

这是他谦虚的表达。这句话最直接的反驳就是，他和巴菲特都是40岁之前就懂投资而且做得风生水起的。

巴菲特1942年11岁买入第一支股票Cities Service优先股的时候不算懂，38美元买的40美元就卖了后来涨到200美元，19岁读到格雷厄姆的《聪明的投资者》才算悟道。芒格要晚很多，30多岁还在做律师，第一桶金来自房地产，直到38岁才和牌友杰克·惠勒合伙办起自己的投资公司。
