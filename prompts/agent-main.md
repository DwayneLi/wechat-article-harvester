# 主控 Agent 提示词（可直接复制给 Claude Computer Use / OpenAI Operator / 自建 Agent）

你把下面整段作为系统提示或任务提示交给执行 Agent。前提：**已装好 Computer Use 能力，且能执行 shell 命令**。

---

```
# 任务
把微信公众号「<公众号名称>」的全部文章归档为 Markdown，并采集每篇文章的互动数据。

# 环境
- macOS，微信 Mac 客户端已登录
- 公众号文章列表窗口在**内建屏、单窗口**状态
- 你有 Computer Use（截图 + 点击 + 滚动 + 键盘）和 bash

# 铁律（违反会导致数据丢失，必须遵守）
1. 每次点击前确认微信在前台（activate + 等 1.3 秒），否则点击会被系统静默丢弃
2. 绝不点击标签栏最右侧的图标（搜索/合并/通知），会触发窗口合并、标签全丢
3. 绝不点击 `···` 菜单里的「关闭全部标签页」
4. 禁用快捷键 Cmd+W / Ctrl+Tab / Cmd+Shift+]，在微信里会关窗口
5. 每次动作前按一次 Esc，清掉可能残留的弹出菜单（菜单会吞掉滚轮事件）
6. 不确定的目标，先用 OCR 确认文本再点，不要盲点坐标
7. 每完成一步就把结果落盘（链接写 CSV、截图存文件），不要攒着

# 阶段 1：采集全部文章链接（每篇 4 步）
1. 在文章列表点击文章**标题**（不要点封面图），新标签打开正文
2. 等 2.5-3 秒加载
3. 点击标签栏中「当前激活标签右端」的 `···` 圆钮 → 菜单 → 点「复制链接」
   - 菜单项按 y 坐标定位：「复制链接」通常是第 3 行
4. 点回最左侧的公众号列表标签
5. 用剪贴板监听脚本自动落盘（避免手工读取）

重复直到列表滚到底部。滚到底后等 3-5 秒，会自动加载更多；连续 3 次无变化才算真的到底。

# 阶段 2：下载正文
对每个链接，调用可用的下载能力（MCP 接口或网页批量下载），把 md 存到 ./md/。
限流时（返回"服务器繁忙"）单线程重试，间隔 2.5 秒。

# 阶段 3：清洗 + 分类 + 归档
按 docs/01-workflow.md 的规则：
- 提取标题/作者/发布时间/地点 → front-matter
- 从「预览时标签不可点」整段截断尾部垃圾
- 删除作者头像图，保留正文图
- 打 ≤3 个语义 tag
- 生成 MOC 索引（分类索引 + 时间索引，[[文件名]] 双链）

# 阶段 4：互动数据（可选，耗时最长）
逐篇打开截图（存 full/bar/hdr 三张，用发布时间命名），然后**离线**用 CV 解析：
- 底部栏：连通域 → 图标模板匹配 → 图标右侧窄高连通域 = 数字 → 字形模板分类
- 顶部行：同理，找 [耳机图标][数字][人]
- 不要用 OCR 整行取数（图标会被读成数字）

# 停止条件
- 所有链接采集完成 + 所有正文落盘 + 所有可解析的互动数据回填
- 或用户中断（此时必须保证已落盘的数据完整、可续跑）

# 每轮结束必须报告
- 新增成功数 / 失败数 / 累计总数
- 当前卡点（如果有）
- 下一步计划
```
